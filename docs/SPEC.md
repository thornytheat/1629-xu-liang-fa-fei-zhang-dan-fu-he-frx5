# 需量罚费账单复核业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括冷冻加工、轻型机加、商业综合体、社区配电。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `observed_kw` | 账期最大需量 kW | 75 至 680 |
| `subscribed_kw` | 签约需量 kW | 100 至 580 |
| `gap_min` | 采集间隙 min | 0 至 29 |
| `multiplicity` | 互感器校验系数 | 0.7 至 1.32 |
| `fee` | 需量罚费 元 | 30 至 3400 |
| `amendment` | 费率已生效 | 0 至 1 |
| `locked` | 账单冻结 | 0 至 1 |

## 计算与裁决

使用正则化逻辑回归，目标单位为 概率。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

| 派生特征 | 计算 |
| --- | --- |
| `over_limit` | `max(0, observed_kw - subscribed_kw)/450` |
| `gap_fraction` | `gap_min/29` |
| `meter_delta` | `abs(1-multiplicity)` |
| `fee_exposure` | `fee/3400` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括账单冻结或费率尚未生效。最终分派受按计量组复核席位总额和组内上限约束，使用额度守恒回读工作单。

## 换档待确认系数

某计量组换档后可能同时留下两个待确认的互感器校验系数（档位），整组最终只会采用其中一档。`coefficients` 记录以 `case_id` 标识：

| 字段 | 含义 | 接受范围 |
| --- | --- | --- |
| `group` | 计量组 | 与业务组一致 |
| `coefficient` | 待确认互感器校验系数 | 0.7 至 1.32 |
| `day` / `arrived` | 发生日 / 入账日 | 同测量记录 |
| `revision` | 修订号 | 1 至 10000 |

同一编号的较新修订覆盖较旧修订，同修订异值整条隔离并留痕；每组最多保留两档，超过两档时保留最近入账两档。只有恰好两档的组进入换档重估。

锁定名单前用两档分别替换该组每张账单的 `multiplicity` 并重估争议概率：

- 一张账单只有在**两档**下都符合现有复核条件（回放门限、分布偏移、人工查表、业务锁）时才可能占席位；任一档不满足即不占席位。
- 两档各自排序得到的名单相同时直接沿用。
- 名单不同时，当班仍只锁一份名单：在席位总额与组内上限内，取两档中较低的预期争议罚费总额尽可能高的一份，并让相同总额下总额更高、占用更少者优先。
- 预期争议罚费按 `fee × 概率 × (1 + gap_min/40)` 计到整数分（`Decimal`，四舍六入五成双），累计只用整数，舍入误差不改变取舍。
- 快照日之后才入账的档位记录对当班不可见，重算不会改变名单。
